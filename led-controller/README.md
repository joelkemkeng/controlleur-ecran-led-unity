# Contrôleur LED

## Description

Application de bureau pour contrôler des écrans de LED via DMX/Art-Net.

## Fonctionnalités principales

- **Routage Art-Net vers DMX** : Recevez des données Art-Net et routez-les vers des univers DMX spécifiques.
- **Moteur d'animation** : Créez et jouez des animations complexes sur les écrans LED.
- **Visualisation en temps réel** : Prévisualisez les animations et les données DMX directement dans l'application.
- **Interface utilisateur moderne** : Une interface intuitive pour gérer toutes les fonctionnalités.

## Lancement de l'application

Pour lancer l'application, exécutez le module `ui.app` :

```bash
python -m ui.app
```
